## Affected Pages/Routes
- `https://map.astroanil.dev/` — primary shot queue UI (top 5 cards, auto-refresh 60s)
- `https://map.astroanil.dev/?view=map` — secondary map view (ISS dot, ground track, cloud overlay)
- `https://map.astroanil.dev/log` — calibration rate-later page (lists recent unrated shoots)
- `https://map.astroanil.dev/api/log` — Cloudflare Worker POST endpoint (calibration ingest)
- `https://map.astroanil.dev/api/health` — Worker GET endpoint (UptimeRobot target)
- `https://map.astroanil.dev/status.json` — generator status (last_run, per-step latency)
- `https://map.astroanil.dev/current.txt` — atomic-publish version pointer (per 2A)

## Key Interactions to Verify
- **Shot card glance** on primary view: target name, countdown, P(unobstructed), regime tag, obstruction class, one-line note all visible in <5s scan
- **Tap Shoot/Skip** on a card: POST to `/api/log` with valid token; queue updates locally; offline retries
- **Auto-refresh every 60s**: stale UI updates without user action; no flash/flicker
- **UTC label** on every time field: countdown ends in `UTC`; pass time renders as `14:23 UTC`
- **Stale banner** transitions: green → yellow at 12 min → red at 30 min
- **Map toggle** from queue view: ground track + ISS dot + cloud overlay render correctly
- **Time toggle** on map view: `Now` vs `+90 min` shifts ISS position and ground track
- **Calibration rate-later** (`/log` page): lists recent unrated shoots; submitting a 1-5 + obstruction-class POSTs and updates list

## Edge Cases
- **Empty queue** (no targets in next 90 min): primary view shows friendly empty state, not blank
- **Stale > 30 min**: scores visually demoted to grey; banner red; POST still works (logs go through)
- **Network failure** to fetch `passes.json`: error UI with "retrying" indicator, not a white screen
- **Antimeridian crossing** in ground track: track renders correctly across ±180° longitude
- **Polar latitudes** in target sampling (lat near ±90): cloud sample doesn't crash on pole singularities
- **Countdown crosses zero**: card transitions from `In 4 min` → `Now (Xm remaining)` → removed from top-5 cleanly
- **Token missing in localStorage**: `/api/log` returns 401; UI shows setup banner with instructions
- **Token expired/leaked**: rate-limit kicks in (10 req/min/IP); UI shows backoff message
- **TLE > 36h since epoch**: scores display with confidence-decay indicator; banner notes orbit-prediction degraded
- **Cloud composite > 90 min stale**: cloud overlay shows last-known-good with stale tag
- **rclone partial sync mid-tick**: `current.txt` not yet updated → frontend continues serving prior version (atomic publish per 2A)
- **Sun-glint over land mask edge**: water-pixel boundary cases (rivers, coastlines) don't false-positive

## Critical Paths (must work end-to-end)
- **Happy-path glance**: page load → see top-5 cards → identify shootable target in <5s
- **Shoot logging**: tap Shoot → POST succeeds → calibration log gets the entry → next tick reads it
- **Stale degradation**: kill generator → page still renders, banner red, scores grey, POST still works
- **Atomic publish**: mid-rclone failure does not produce torn reads on the frontend
- **Daemon recovery**: kill generator → launchd respawns within seconds → next tick rewrites status
- **Reboot recovery**: force kernel reboot on the Mac → daemon resumes → site recovers within 1 tick
- **Token revocation**: rotate Earthdata token → next tick fails fetch → retries → eventually alerts via UptimeRobot webhook → ground-side fixes per runbook

## Soak-Test Injection Scenarios (2-week pre-launch)
- Kill network for 30 min during a tick; verify cached fallback + stale banner
- Kill the daemon process; verify launchd respawns and next tick succeeds
- Manually edit cached TLE to be 36h old; verify confidence downrank visible in UI
- Revoke Earthdata token; verify fetch fails, retries, alert fires
- Force kernel reboot; verify auto-login + launchd auto-start + tick within 5 min

### Additional ops scenarios (added by /plan-eng-review outside voice)
- **Locked-screen reboot.** Reboot while user is logged in but screen-locked. Verify daemon resumes (this tests the keychain-locked path that 1B flagged as accepted risk).
- **Mixed-cache deploy.** Force a tick mid-rclone, abort, then load the page from a browser with cached `index.html` from the prior version. Verify the manifest pattern prevents mixed-version reads.
- **Clock skew on Mac.** Manually set system clock +5 min, +30 min, −2 min. Verify pass-time calculations stay correct (should — UTC end-to-end discipline) and that UptimeRobot health check still works despite skew.
- **Corrupt upstream files.** Replace cached SatCORPS NetCDF with random bytes. Verify graceful failure path + alert.
- **ISS-side viewport / network.** Test page on iOS Safari mobile viewport, on a throttled connection (Chrome DevTools "Slow 3G"), and after an offline reload. Verify the page renders, shows the right banner, and the calibration POST queues for retry.
- **"Stale but green" assertion.** Force `freshness.tle_hours > 36` AND `freshness.cloud_hours > 2`. Verify the banner is RED and scores are visually demoted, even if the generator successfully ticked recently. UI must never imply confidence when *inputs* are beyond thresholds.
- **R2 outage simulated.** Block `*.r2.cloudflarestorage.com` at firewall during a tick. Verify generator retries, eventually alerts, doesn't corrupt local state.
- **DNS failure.** Block `celestrak.org` at firewall. Verify cached TLE is used + alert fires after threshold.
- **Earthdata token rotation drill.** Pre-launch: actually rotate the Earthdata token end-to-end; time how long it takes; document in runbook so the ground-side support knows the procedure cold.

## Test Implementation Sketch
- **Python** (generator): pytest. Modules: `orbit.py`, `cloud.py`, `score.py`, `main.py`. Golden-file fixtures for sgp4 + NetCDF; mock HTTP for Earthdata + Celestrak. Coverage gate ≥ 90% line, 100% branch on `score.py`.
- **TypeScript Worker**: vitest + miniflare for Cloudflare Workers local emulation. Mock R2.
- **Frontend**: vitest + happy-dom for unit; Playwright for E2E flows (happy path, stale, token-missing, countdown-crosses-zero).
- **CI**: single GitHub Action workflow; `make test` runs all three suites + emits coverage report.
- **Soak**: `tools/inject_failure.sh <scenario>` script encapsulates each injection above; runbook calls these by name.
